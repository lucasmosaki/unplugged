# FORENSIC MYSTERY: The Last Track

Run:  `python3 main.py`   
Flags: `--fast` `--mute`, `--continue`
Tests: `python3 -m unittest discover tests`
Optional: `pip install pygame` for the lowest-latency typing sounds.

#FYI
- Sound also works with afplay (macOS), paplay/aplay (Linux) or winsound (Windows).
- Ctrl+C Skips message.

Presentation tip: make the terminal font large and the window full screen.
